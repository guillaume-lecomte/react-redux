# react-redux

A small React and Redux exercise: a bookstore list where books can be added, viewed and removed.

**Status: archived.** Learning exercise, first commits in 2019, last activity 2020-11-07. Not maintained.

## What it shows

- A store, actions and a reducer for the book list, with ids generated by `uuid`: [`store.js`](src/store.js), [`bookActions.js`](src/actions/bookActions.js), [`bookReducer.js`](src/reducers/bookReducer.js).
- Containers that connect the store to presentational components with `connect`: [`BooksListContainer.js`](src/containers/BooksListContainer.js), [`AddBookContainer.js`](src/containers/AddBookContainer.js), [`BookDetailsContainer.js`](src/containers/BookDetailsContainer.js).
- The state lives in memory only. The four starting books are defined in the reducer.

## Stack

From [`package.json`](package.json): React 16.8, Redux 4, `react-redux` 6, `react-scripts` 2.1.8 (Create React App), Font Awesome icons.

## Run it

```bash
yarn install
yarn start
```

These commands were not run when this README was written.

## Known issues

- The dependencies are from 2019 and 2020 (`react-scripts` 2.1.8) and `yarn audit` reports a large number of advisories for them. Do not deploy this as is.
- The only test is the default Create React App one.
